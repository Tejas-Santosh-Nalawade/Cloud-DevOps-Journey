# DevOps Journey (2026)

This repository documents my **day-by-day DevOps learning journey** starting from  
**January 1, 2026**.

The focus of this journey is to build a **practical, production-oriented
understanding** of how modern software systems are **built, shipped, scaled, and
operated**.

Everything here is tracked **daily**, with clear structure, notes, and hands-on
work.

---

## How This Journey Is Structured

This journey is divided into **phases**, and each phase is documented in a
**day-wise format**.

Each topic is broken down into **Day 1 → Day N**, depending on how much time it
needs.

Example:
- Linux: Day 1 – Day 6  
- Docker: Day 7 – Day 12  
- CI/CD: Day 13 – Day 20  

This approach helps maintain:
- Consistency
- Depth of understanding
- Real progress over time

---

## Journey Timeline

- **Duration:** ~3 months  
- **Tracking:** Daily  
- **Approach:** Foundations → Shipping → Scaling → Production  

---

## Phases & Learning Focus

### Phase 1: Foundations
**Goal:** Build strong system fundamentals

**Learning Includes:**
- Linux & operating system basics  
- Networking fundamentals  
- Git & GitHub workflows  
- Shell scripting  
- Cloud fundamentals  

---

### Phase 2: Shipping Software
**Goal:** Learn how code reaches production

**Learning Includes:**
- Docker & containerization  
- CI/CD pipelines  
- Infrastructure as Code  
- Cloud deployments  
- Secure build and release workflows  

---

### Phase 3: Scaling Systems
**Goal:** Understand scalability and reliability

**Learning Includes:**
- Kubernetes fundamentals  
- Cloud-native architecture  
- Load balancing & autoscaling  
- Monitoring & logging  

---

### Phase 4: Production & Reliability
**Goal:** Operate systems in real environments

**Learning Includes:**
- System design for scale  
- Observability & incident response  
- Cost optimization  
- Security best practices  

---

### Phase 5: MLOps (Future Phase)
**Goal:** Extend DevOps practices to ML systems

**Learning Includes:**
- Model deployment pipelines  
- ML infrastructure  
- Monitoring ML systems in production
